# Starbucks Analysis – Power BI

## Project Overview

This project is an interactive Starbucks Beverage Analysis Dashboard created using Microsoft Power BI.

The dashboard analyzes Starbucks beverages based on calories, sugar, caffeine, beverage categories, and global presence.

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Key KPIs

- Total Beverages: 33
- Average Sugar: 33.02
- Average Calories: 194.30
- Average Caffeine: 81

## Dashboard Analysis

The dashboard provides analysis of:

- Average Calories by Beverage Category
- Starbucks Global Presence
- Beverage Category Distribution
- Average Caffeine by Category
- Top 5 Highest Caffeine Beverages
- Average Sugar and Calories
- Beverage-level analysis

## Key Insights

- The dashboard compares different Starbucks beverage categories based on nutritional values.
- Caffeine levels vary significantly across beverage categories.
- The dashboard highlights the beverages with the highest caffeine content.
- Calorie and sugar levels can be compared across different beverage categories.
- Starbucks global presence is visualized using category-level analysis.
